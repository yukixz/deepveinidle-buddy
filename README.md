# 工匠与精通助手 · Crafting & Mastery Buddy

在游戏内运行的制造／收藏混合订单助手，使用 userscript 和 Shadow DOM，实时同步角色数据，汇总采购材料与执行计划。

项目处于开发阶段，计算基线 **1.0.1199**，未发布。只维护当前数据结构和 DVILAB-PLAN 单订单格式。

## 本地开发

```sh
npm ci
npm run build
npm start
```

打开终端输出的地址体验演示。演示使用合成角色和独立存储，不连接游戏账号或读取实时行情。

```sh
npm test
npm run test:ui
```

UI 验证需要演示服务和 Chrome；可通过 `BUDDY_URL`、`CHROME_PATH` 指定地址和浏览器。结果保存在 `.test-artifacts/verification/`，也可用 `node scripts/test-ui.mjs 场景名` 单独运行。

## 安装与操作

在脚本管理器安装 `dist/deepveinidle-buddy.user.js`，刷新游戏载入新脚本并等待角色数据；已载入的脚本可直接读取当前登录角色，无需等待新快照。“工匠与精通助手”入口位于“游戏导航”末尾，前方有分隔线；关闭面板后从这里重新打开。

- 标题栏提供语言切换和关闭；拖动标题移动，四边／四角可调整大小，允许贴边，无角落标记。位置与尺寸在刷新后保留。
- 配方模式从左到右为收藏(制造)、收藏(采集)、制造，品质默认“全部”。物品和稀有度独立排序；收藏支持金币、精通点、时间等指标排序，成本列与筛选使用“金币/点(M/100)”。
- 页码和翻页按钮靠左，“全部加入订单”靠右，加入当前筛选的全部页。制造保留已填次数，新配方按1次；收藏同物品取最高目标。
- 点击订单汇总行展开／收起详情并切换当前订单；勾选执行、复制和删除独立操作。详情内可编辑名称、费用和条目，并通过剪贴板交换 DVILAB-PLAN 订单。
- 固定金额单位为 M，工时单价为 M/h，1M 为100万金币；材料费率按需求材料总价值加收。订单列表依次显示时间、材料成本、加工费及建议售价（成本＋加工费），未勾选订单也独立估算。
- 执行计划汇总采购、时间、精通点，先显示采购材料，再显示执行动作。绿色边框表示本动作涉及的每种材料均满足其计划总需求，黄色边框表示够本动作但至少一种相关材料仍未达到总需求；当前游戏任务以紫色底色标记，队列任务以蓝色底色标记，与材料边框共存；悬停整行查看说明。

角色配置只读同步，面板不运行模拟。前台相关字段变化后1秒内更新；输入法组合期间保持输入节点，并局部更新只读结果。
