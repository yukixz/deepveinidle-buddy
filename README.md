# 工匠精通助手 · Crafting & Mastery Buddy

在Deep Vein Idle游戏内运行的userscript，提供制造订单、收藏规划、材料采购与执行计划。版本 **0.5.12**，计算基线 **1.0.1214**。

[安装与更新](https://greasyfork.org/zh-CN/scripts/601896-deepveinidle-buddy) · [GitHub Releases](https://github.com/yukixz/deepveinidle-buddy/releases)

## 使用

从游戏导航打开助手，按角色保存订单、模式、筛选及定价选择。

助手按每个动作的技能绑定选择精通页，未绑定时使用游戏当前生效页。混合订单与半成品分别估算，切页等待按零计算。

| 模式 | 用途 |
| --- | --- |
| 制造 | 管理多订单、固定执行次数、收藏条目及费用，汇总采购与执行计划 |
| 收藏（制造） | 将收藏目标加入独立固定计划，调整目标或移除；通过「半成品策略」下拉框，可为金属锭和切割宝石的缺口选择择优、购买或自制 |
| 收藏（采集） | 比较各品质合计的收藏收益与效率，展开查看品质明细，不创建订单 |

材料和产物可分别按市场卖单／买单估值；材料还支持在售数量与库存筛选。采购抵扣同品质未锁定的仓库、背包及预计产物，缺少库存或行情时显示未知。收藏次数为期望估算，不保证实际完成目标。

“购买／执行”仅打开游戏菜单并预填草稿，最终由用户确认。角色与行情只存本页内存，刷新后重新读取。桌面支持拖动缩放，移动端使用紧凑表格与横向滚动，语言跟随游戏。关闭后重开保留本页输入与滚动，刷新默认关闭。

## 存档与更新

更新前可在脚本管理器备份脚本数据，旧版脚本可能无法读取新增字段。订单可在助手内复制，不提供文本或剪贴板导入导出。

存档报错时会保留原值；先备份管理器中的原值，再重新载入或明确重置。回退显示的默认订单不代表数据已恢复。

## 本地开发

```sh
npm ci
npm test
npm run build
npm start
```

演示使用合成角色和独立存储，不连接游戏账号。默认演示地址为 `http://127.0.0.1:4178/`；保持服务运行，在另一终端执行 `npm run test:ui` 验证浏览器场景。GitHub Actions执行相同检查；发布步骤见[构建与发布](docs/releasing.md)。
