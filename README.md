# 工匠精通助手 · Crafting & Mastery Buddy

在游戏内运行的制造／收藏混合订单助手，使用 userscript 和 Shadow DOM，实时同步角色数据，汇总采购材料与执行计划。

当前版本 **0.2.0**，项目处于开发阶段，计算基线 **1.0.1199**，未发布。只维护当前数据结构和 DVILAB-PLAN 单订单格式，不提供历史版本兼容或迁移。

## 本地开发

```sh
npm ci
npm run build
npm start
```

打开终端输出的地址体验演示。演示使用合成角色和独立存储，不连接游戏账号或读取实时行情。

```sh
npm test
npm run test:ui
```

UI 验证需要演示服务和 Chrome；可通过 `BUDDY_URL`、`CHROME_PATH` 指定地址和浏览器。结果保存在 `.test-artifacts/verification/`，也可用 `node scripts/test-ui.mjs 场景名` 单独运行。

## 安装与操作

在脚本管理器安装 `dist/deepveinidle-buddy.user.js`，刷新游戏载入新脚本并等待角色数据；已载入的脚本可直接读取当前登录角色，无需等待新快照。“工匠精通助手”入口位于“游戏导航”末尾，前方有分隔线；刷新页面后助手默认隐藏，入口旁显示5秒文字提醒；点击入口打开，关闭后仍可从这里重新打开。游戏移动模式下入口仅在主画面显示，位于聊天按钮上方；进入游戏、背包、市场等界面时隐藏，返回主画面后恢复。助手打开时，点击底部操作栏成功切换页面会自动关闭助手；返回主画面后可从入口重新打开。

- 标题栏仅保留关闭按钮，语言跟随游戏；角色与市场状态使用简短标签，游戏版本位于窗口内容最底部。桌面可拖动标题移动，四边／四角可调整大小，允许贴合左右与底部边缘，顶部避让游戏工具栏，无角落标记。桌面位置与尺寸在刷新后保留。移动面板上方和左右贴合可视区域边缘，仅避开下方操作栏；标题栏与游戏顶部功能栏等高，适应键盘，不显示拖动缩放热区，也不覆盖桌面布局存档。
- 配方模式从左到右为收藏(制造)、收藏(采集)、制造，默认选择收藏(制造)，品质默认“全部”。材料可选“卖单（排除在售数量不足）”，按制造单次／收藏目标预计材料总需求筛选，不扣库存，供应信息未知的候选也排除。物品和稀有度独立排序；收藏支持金币、精通点、时间等指标排序，“金币/点”列显示实际每点金币数，与“金币”列统一使用K、M等后缀并保留两位小数；筛选输入仍使用M/100。
- 页码和翻页按钮靠左，“全部加入订单”靠右，加入当前筛选的全部页。制造保留已填次数，新配方按1次；收藏同物品取最高目标。
- 点击订单汇总行展开／收起详情并切换当前订单；勾选执行、复制和删除独立操作。详情内可编辑名称、费用和条目，并通过剪贴板或“计划文本”区域交换 DVILAB-PLAN 订单；剪贴板受限时可手动复制、粘贴。“自动移出已完成的收藏目标”默认关闭，已有存档保留用户设置。
- 固定加工费单位为 M，工时单价为 M/h，1M 为100万金币；材料费率按需求材料总价值加收。订单列表依次显示时间、材料成本、加工费及建议售价（成本＋加工费），未勾选订单也独立估算。
- 执行计划汇总采购、时间、精通点，先显示采购材料，再显示执行动作。采购表按“需求 / 库存 / 产物”列出数量，采购金额使用扣除库存和预计产物后的缺口；产物按期望估算，不保证实际产量或动作先后可执行性。
- 执行动作的深绿色底色表示本动作涉及的每种材料均满足其计划总需求，琥珀色底色表示够本动作但至少一种相关材料仍未达到总需求；当前游戏任务以紫色边框标记，队列任务以蓝色边框标记，与材料底色共存；整行保留悬停说明，双端使用相同状态样式。

移动表格使用紧凑字号及留白，窗口内按钮、单行输入框及下拉框统一32px高度，保留全部数据列；冻结的物品名最多显示两行，点按可展开全文。订单汇总与展开详情共用一个横向滚动区域，上下滑动仍滚动助手正文。

角色配置只读同步，面板不运行模拟。正式脚本行情仅保存在内存，刷新页面或切换角色后重新获取。前台相关字段变化后1秒内更新；界面节点保持稳定，数值和状态局部更新；滚动、拖动、文本选择期间延后结构变化，控件编辑期间保留草稿及选项。中文输入共用同一更新机制。

采集品质、收藏期望和预计产物使用来源游戏tick的稀有度热门及有效世界加成；非法时间或世界数据会保留有效角色并报告错误。助手不预测未来热门时段，也不计算经验或旅行收益。

存档只接受当前字段结构；缺少必填字段或包含废弃字段时明确报错并保护原数据，不自动迁移或覆盖。面板使用解析期望计算，模拟对照代码仅用于本地测试。
