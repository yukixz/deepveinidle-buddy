# 初版实施与验证

日期：2026-10-22。候选版本 0.1.0，未发布，未安装到真实脚本管理器。此报告属于新项目本次实际执行，不引用实验室历史通过结果作为本轮验收。

## 实现

- 独立项目，源代码／依赖锁定／构建／本地演示／测试齐备。29 个必要计算模块从实验室 main 复制，来源及逐模块摘要见 vendor/lab-source.json；完整公开上游资源及 manifest 随项目保存。
- 单一 userscript，应用在 open Shadow Root 内运行，内嵌独立打包的 Blob Worker；没有远程 require、运行时下载执行或额外游戏 WebSocket。
- 配方选择切换制造／收藏，保留五种制造与九种收藏技能；同一订单混合固定次数与累计收藏目标。支持新建、复制、命名、删除、批量制造次数、整单执行、目标升降和自动移除完成收藏。
- 混合材料跨执行订单合并后统一取整、只抵扣一次 bank＋pack；保留未知库存、缺价／小计、数量超限、跨单收藏冲突及同配方任务未联合抵扣提示。耗时分制造模拟和收藏动作期望，混合时间费未知时不伪装完成总价。
- 配置／库存／收藏进度推送，断线可见；按角色与站点分桶 GM 存储、并发版本检测、坏存档保护。角色配置和订单编辑分离，保留焦点及文本草稿，制造／收藏各自保存筛选。
- 公开行情、手动锁价、旧制造工作区／旧收藏压缩计划迁移、新订单 JSON 文件／文本交换；订单导入不覆盖角色与库存。
- 棕金面板、字体、边框与按钮参考实际游戏 computed style；参数见 theme-sample.json。桌面／窄屏、本地双语截图见下方。

## 边界与未验证

- 引擎固定为 1.0.1199。采样页提示游戏已更新到 1.0.1200；本次没有同步或审计 1200 规则，新版数据出现未知结构／物品时须明确失败，不猜测映射。
- 未安装或更新用户脚本管理器，未执行真实游戏指令或真实游戏内挂载验收；浏览器验证只使用本地合成消息。不能据此认定实际管理器注入足够早、CSP 允许 Blob Worker、游戏快捷键完全不冲突或长时性能已通过。
- 真实游戏样式采样时新开的页面自动恢复已有登录会话，并出现“正在其他位置游玩”；已关闭该页，没有点击切换游玩或发送游戏命令。只保存样式参数，不保存账号、库存、聊天或游戏截图。
- 仅跟随服务器角色快照，不镜像游戏客户端逐刻预测；新旧状态显示捕获时间。GM 无原子比较交换，跨标签并发为尽力检测，极端同时写入待真实管理器验证。
- 未执行真实行情网络成功／管理器权限、1200 真实角色兼容、独立生产发布、像素级原生样式对照。实验室现有页面和发布状态未改变。
