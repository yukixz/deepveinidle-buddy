# 实时同步与菜单预填验收

日期：2026-10-22。已实施用户确认范围；后台休眠、断网和主线程阻塞不在1秒同步验收范围。当前行为见[面板设计](../docs/panel.md#游戏同步与草稿预填)。

## 实现

- `game-sync.js`每250ms复制游戏暴露的客户端白名单，不读取凭据或聊天，不调用预测推进器、不新建连接。服务器快照独立保留，客户端失效时明确降级；来源、序号和角色分别校验。
- `main.js`支持已有登录状态直接挂载和客户端切角；GM加载过程中切角会丢弃过时挂载。`app.js`在实质变化时重绘、合并保存，输入法组合期间仅替换只读区域，保留输入节点和横向滚动。
- `game-prefill.js`只接受已核验1.0.1200资源摘要，用户点击后即时重读相关行并在异步步骤核对角色与请求。市场按物品ID定位，使用可编辑求购草稿，失焦后校验数量和价格；普通制造及采集只选择配方和次数，不调用开始、排队、停止或即时设置。
- 收藏聚合期望次数统一向上取整，提示不保证完成收藏。升级入口禁用；已有草稿、未知版本、角色或请求变化、缺价、控件缺失、稀有度不可用及被游戏调整的输入均明确拒绝。
