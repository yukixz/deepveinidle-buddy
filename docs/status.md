# 当前状态

更新日期：2026-10-25。开发版本 **0.2.0**，main包含移动紧凑表格、订单横向滚动及冻结任务边框修复；未发布、未部署。计算基线 **1.0.1199**，曾与1.0.1200公开程序的778项相关声明比较，源码相同。

## 当前功能

- 双端默认共用设计与UI，必要差异见[双端设计原则](panel.md#双端设计原则)。刷新默认隐藏助手，入口就绪时显示5秒打开提醒；语言跟随游戏，标题保留助手版本、角色和市场状态，游戏计算版本位于窗口内容最底部。
- 制造／收藏混合订单、共享定价、材料供应筛选、费用、采购与动作汇总、DVILAB-PLAN单订单传输；计划文本、剪贴板和存档校验共用规则。收藏期望次数在执行计划中先向上取整，采购扣除库存及预计产物。配方、采购、动作表冻结物品与稀有度两列。
- 材料满足状态用绿色／琥珀色底色，当前动作／队列用紫色／蓝色边框；冻结两列在自身底色上方补绘上下边框及左侧标记，横滚和悬停不缺边。实时任务状态只保留内存。只读同步每250ms采样，正常前台变化后1秒内更新；稳定节点保留滚动、编辑草稿和输入法交互。
- 桌面面板层级7，可拖动缩放、保存位置尺寸并避开顶部工具栏。移动层级31，顶边与左右贴合可视区域、只避开底部操作栏；标题与游戏顶部功能栏等高，适应键盘，不写回桌面布局。移动标题长按打开隐藏菜单；执行状态双端统一使用底色、边框及行title，无移动专用状态按钮或详情。
- 移动表格字号12px，窗口内所有按钮、单行输入框及下拉框统一32px（含标题栏与隐藏菜单），数字输入保留16px字号；缩小分区留白，冻结物品列72px、长名称两行并可聚焦展开。订单容器不再被宽表撑开，汇总与展开详情共用一个横向滚动层，上下滑动继续滚动正文。
- 移动入口只在主画面聊天按钮上方显示，进入其他页面或弹窗后隐藏。用户点击底栏成功进入目标页面后自动关闭助手；返回主画面保持关闭，重新打开保留订单、输入及滚动。
- 购买／执行辅助仅为隐藏调试功能，只导航并预填草稿，不提交交易或角色动作。程序导航不触发上述用户切页关闭规则；移动预填成功后关闭、失败保留，电脑端保持显示。正常完成不提示，处理中／失败在原入口位置显示5秒，入口隐藏不丢失错误反馈。移动动作预填须同时确认根元素和移动容器为play，避免市场覆盖层被当作游戏页。
- 正式脚本行情仅存内存，刷新及切角后重新读取；订单、角色快照和定价偏好继续保存。按单个游戏页面运行，写入前检查revision，串行保存并保护坏存档；没有跨页面存储监听。

具体交互、计算与验收以[面板设计](panel.md)为准；实现及上游来源见[技术方案](technical.md)。
