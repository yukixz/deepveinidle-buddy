# 当前状态

版本：**0.3.3**。计算基线：**1.0.1204**。发布记录以[GitHub Releases](https://github.com/yukixz/deepveinidle-buddy/releases)与[Greasy Fork](https://greasyfork.org/zh-CN/scripts/601896-deepveinidle-buddy)为准；历史变更见[更新说明](../CHANGELOG.md)。

## 功能范围

- 三模式：制造保留完整多订单、费用及传输；收藏（制造）使用独立固定单，在执行计划升降目标或移除；收藏（采集）仅显示配方。首次默认制造，按角色恢复模式及三套筛选。
- 模式和材料／产物定价位于配方区之前，定价始终显示。采集配方显示独立执行次数，不显示金币和金币／点列。
- 采购显示完整材料成本与抵扣后的采购成本，保留需求／库存／预计产物数字，不折叠。收藏固定单的自动移除选项在执行计划标题行，目标操作顺序为＋、−、×。
- 角色、库存、收藏与任务只读同步；材料满足、当前动作和队列使用底色及边框。模式切换取消过期导入和预填，旧控件不能编辑新模式。
- 双端共用规则；桌面拖动缩放，移动紧凑表格、冻结列及横滚；刷新默认关闭窗口，入口无自动提示。
- 工作区version=2保存订单、界面输入及可选collectionOrder／selectedMode；完整保留旧混合订单于制造模式。字段缺失与损坏分别处理，读取不自动写回，新增字段不支持旧版降级。角色与行情只存会话内存，串行保存及revision冲突保护保留。
- GitHub Actions验证与tag发布，仓库Webhook同步Greasy Fork；构建绑定版本、来源提交和摘要。统一入口见[发布日常入口](releasing.md#日常入口)。
