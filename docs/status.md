# 当前状态

版本：**0.3.3**。计算基线：**1.0.1204**。发布记录以[GitHub Releases](https://github.com/yukixz/deepveinidle-buddy/releases)与[Greasy Fork](https://greasyfork.org/zh-CN/scripts/601896-deepveinidle-buddy)为准；历史变更见[更新说明](../CHANGELOG.md)。

## 功能范围

- 制造／收藏混合订单、共享定价、材料供应筛选、费用、采购与执行计划，DVI-BUDDY-PLAN单订单导入导出。
- 角色、库存、收藏与任务只读同步；材料满足、当前动作和队列使用底色及边框标记。
- 双端共用规则和UI，桌面拖动缩放，移动紧凑表格、冻结列及横向滚动；刷新默认关闭面板。
- 用户工作区version=2，仅保存订单和界面输入；角色与行情只存内存。串行保存、写前校验、revision冲突保护、显式重新载入和重置。
- GitHub Actions验证与tag发布，仓库Webhook同步Greasy Fork；构建绑定版本、来源提交和摘要。
