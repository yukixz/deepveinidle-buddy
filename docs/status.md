# 当前状态

版本：**0.3.3**。计算基线：**1.0.1204**。发布记录以[GitHub Releases](https://github.com/yukixz/deepveinidle-buddy/releases)与[Greasy Fork](https://greasyfork.org/zh-CN/scripts/601896-deepveinidle-buddy)为准。

## 功能范围

- 制造／收藏混合订单、共享定价、材料供应筛选、费用、采购与执行计划，DVI-BUDDY-PLAN单订单导入导出。
- 角色、库存、收藏与任务只读同步；材料满足、当前动作和队列使用底色及边框标记。
- 双端共用规则和UI，桌面拖动缩放，移动紧凑表格、冻结列及横向滚动；刷新默认关闭面板。
- 用户工作区version=2，仅保存订单和界面输入；角色与行情只存内存。串行保存、写前校验、revision冲突保护、显式重新载入和重置。
- GitHub Actions验证与tag发布，仓库Webhook同步Greasy Fork。源代码、元数据和构建产物绑定同一版本及来源提交。

## 0.3.1变更

配方选择的收藏时间筛选改用小时／100点，内部与存档仍为秒／点，兼容已有version=2存档。成本筛选输入仍为百万金币／100点，存档为金币／点；表格效率列仍显示秒／点和金币／点。

## 0.3.2变更

适配游戏1.0.1204，更新公开资源快照、SHA-256、语义映射与生成引擎。新增纯煤采集路线，普通煤收藏可选、稀有煤收藏排除；产物抵扣始终只计普通煤，补充中文名称。

配方选择的制造、收藏（制造）、收藏（采集）分别保存筛选、排序与页码。version=2兼容读取旧两套筛选存档，新增collectionGather保存采集筛选；定价仍全局共用。

本次计算与构建验证：163项单元测试（含来源摘要与确定性提取）及构建通过。完整24个隔离浏览器场景通过（共285项检查），覆盖纯煤中英文筛选、路线选择、订单与执行来源显示、只读接入、存储、输入法及双端布局；发布元数据与摘要校验通过。未执行真实脚本管理器或账号验收。

## 0.3.3变更

修复移动端执行草稿预填误调用桌面面板接口，导致背包与装备节点持续隐藏的问题。移动端仅使用原生底栏进入技能页，桌面保持原有面板导航。

修复助手打开时，再次点击当前底栏标签返回主画面，助手仍遮挡游戏的问题。原生导航完成后确认页面切换再关闭助手；导航未变化、程序点击和桌面行为保持原规则。

回归检查覆盖桌面面板隐藏副作用、预填后返回背包及当前标签返回主画面。存档格式仍为version=2，计算基线仍为1.0.1204；未执行真实脚本管理器、账号或移动真机验收。

本次发布验证：锁定依赖安装、163项单元测试、构建及完整24个隔离浏览器场景（共288项检查）通过。发布包绑定最终来源提交并校验元数据与摘要，远程发布门禁及同步结果以Actions记录为准。
