# 面板与订单规则

## 交互

userscript 在 document-start 只读监听现有同源 /ws，DOM 可用后挂载唯一 open Shadow Root。面板提供折叠、扩大、关闭／重新打开。UI 样式从公开游戏样式及可读面板采样，局部维护主题，不依赖压缩 class 名。浏览器演示使用本地独立存储，不与真实游戏存档混合。

配方选择分制造和收藏：制造五技能／品质／搜索、等级／速率／成本／利润、次数；收藏九技能、采集／制造分类、品质、目标档、进度／精通点／动作时间／每点指标。筛选不影响订单。支持分页，收藏等级不足及已完成目标不进入候选。

订单可新建、复制、删除、命名、整单执行，当前编辑与执行选择独立。首张空订单自动建立。同单可混合两类条目；制造按配方＋品质更新次数，0 移除；收藏按物品＋品质只保留一条来源及最高目标，同来源重复加入幂等，换来源显式替换。收藏目标可增减档，批量次数仅作用于制造。复制不复制库存或进度。

## 计算

制造复用 1199 原始模拟及产物期望；材料需求是固定次数配方消耗，限时／失败结果不冒充完成。收藏复用纯动作到达期望，不含移动与成长；目标缺口、预计执行次数分开显示；默认自动移除已完成收藏行，未初始化不当零。不同执行订单重复收藏物品＋品质视为冲突，总计划未完整计算；固定制造与同配方收藏是独立任务，提示不联合抵扣。制造耗时和收藏动作期望分开，不给精确联合 ETA。

全精度材料跨所选订单合并后，每种完整物品 ID 统一向上取整，再扣一次已知 bank＋pack；不抵预期产物、不含 overflow／装备。未知库存不是零，无法计算项保持阻塞，材料备齐按全计划需求而不是每单独占库存。收藏奖励不重复相加。

统一采购模式 global／ask／bid／vendor，缺价不自动兜底；已知部分小计明确标注。固定费每张有有效任务订单一次，比例费按全部材料消耗价值而非采购缺口。制造时间费按完整模拟耗时，含未完成收藏且时间单价为正时该项及总费用未知。制造利润可使用既有商人兜底估值，但须标注估值来源。

## 数据与保存

跟随游戏／手动试配分开。共享九技能配置；配置、收藏进度、库存分别比较更新。配置变化才使相关模拟缓存失效，库存更新只改采购，价格更新只改估值，输入草稿和订单不会被后台重绘覆盖。折叠暂停模拟，恢复使用最新快照；异步响应核对连接和序号，断线和旧数据可见。世界／药剂到期按最近有效快照重新派生配置，不伪造库存捕获时间。

使用 GM 独立命名空间，先读后写、串行合并保存。角色标识使用已核验 welcome.you.id；未知身份时显示错误，不读取或覆盖任何角色存档。多标签页写入基于 revision，检测到并发后明确阻止覆盖并要求重新载入；GM 无原子比较交换，本机制为尽力检测，极端同时写入仍需真实管理器验证。坏存档原值保留，明确重置后可写。

导入支持新混合订单 JSON、旧制造工作区及旧收藏 JSON／压缩计划。只迁移订单意图，不导入旧角色覆盖当前游戏；完整校验后应用，失败保留现状。支持文件和文本导入及 JSON 下载／复制导出。

## 验收

覆盖混合订单校验、去重／来源替换、最高档、跨单冲突、共享材料一次抵扣及合并取整、未知库存、完成移除、加工费、旧格式迁移、坏数据和溢出；捕获合帧／换角色／断连／旧帧；实际 Blob Worker、DOM／CSS 隔离、输入保护、折叠恢复、保存刷新、双语窄屏。真实账号与脚本管理器另行验证。
