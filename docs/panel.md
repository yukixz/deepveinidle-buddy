# 面板与计算规则

## 双端设计原则

桌面与移动端共用业务规则、字段和操作。移动端只在布局、键盘及触屏交互上适配，不删减计算数据。面板使用游戏风格的Shadow DOM，语言跟随游戏；标题显示助手版本、角色读取时间及市场读取时间。

刷新默认关闭面板，入口就绪时不显示自动提示。关闭仅隐藏窗口，本页订单、草稿和滚动保留。桌面入口附加于游戏导航；移动入口仅在主画面聊天按钮上方显示，进入其他页面或弹窗后隐藏。

桌面层级7，标题可拖动，四边／四角可缩放；保存位置尺寸，避开游戏顶部工具栏。移动层级31，顶边和左右贴合可视区域，只避开底部操作栏，适应系统键盘；不写回桌面布局。

正文分区按内容高度从顶部排列，保持固定间距；模式切换、筛选后内容减少或窗口增高时，不将剩余高度分摊到分区及其内部元素，空余空间留在正文底部。

移动表格12px字号，按钮、单行输入和下拉框32px高，数字输入16px字号。物品列72px，长名两行并可聚焦展开；宽表内部横滚，冻结物品与品质两列，保持底色及上下任务边框。订单汇总与详情使用同一横滚层，正文继续纵滚。

## 配方与订单

窗口全局设置位于配方区之前，模式从左到右为制造、收藏（制造）、收藏（采集）。材料／产物定价始终显示一组，不根据模式隐藏。首次使用默认制造，之后按角色恢复最后选择的模式；刷新仍默认关闭窗口。

收藏（采集）只显示配方选择，不创建订单，不显示加入／全部加入订单；调试开启后配方操作列提供“执行”，按当前行目标的最新期望次数向上取整预填采集草稿，不选择随机产出品质、不启动游戏动作。调试关闭时移除该操作列。

配方表的收藏执行次数不再附在“当前→目标”内，仅在收藏（采集）显示独立“执行次数”列，位于操作列左侧；调试关闭无操作列时为最后一列。该列沿用原期望次数及显示精度，预填仍向上取整。收藏（制造）配方表不显示执行次数，次数在执行计划查看。收藏（采集）删除金币、金币／点两列，保留其他筛选与估值规则；原金币排序在进入该模式时改用秒／点排序，不改变存档格式，读取时不自动保存。

收藏（制造）显示配方选择、采购材料和执行计划，不显示订单管理。候选加入独立的唯一固定订单，配方中保留已有移出／替换来源行为。执行计划按收藏条目展示，增加当前→目标及操作列，支持按游戏阈值升降目标和移除；这些编辑不受调试开关影响，调试开启时另显示仅预填的执行。完成、不可计算及筛选外条目仍可管理；完成项不计动作。自动移出已完成目标位于执行计划标题行右上角。操作列的目标编辑按钮按＋、−、×排列；×保留“移除”可访问名称和悬停说明，调试开启时“执行”位于其后。固定单无名称编辑或费用。

制造显示完整配方选择、订单管理、采购材料、执行计划，保留现有混合订单。当前编辑订单与执行勾选的规则不变。各模式计算范围独立：制造仅合计其勾选订单，制造收藏只计算固定单，采集仅计算点击的候选。采购独立为分区，不在执行计划重复。“产物按期望估算”位于采购材料面板标题行右上角，其下并列显示材料成本与采购成本；双端保持相同信息层级。

三个模式分别保留技能、品质、名称、收藏阈值、排序和页码，切换或刷新时恢复对应模式的值；修改筛选或排序仍回到第一页。筛选含技能、品质、名称搜索；收藏另含最低精通点、最高小时／100点和最高金币／点，阈值为空表示不限。时间阈值在界面使用小时／100点，内部比较与存档仍使用秒／点（1小时／100点=36秒／点），已有存档按此比例换算显示，存档格式不变；表格时间效率列仍显示秒／点。每页10项，排序在分页前执行，未知值置末。

材料定价支持卖单、卖单（排除在售数量不足）、买单，默认卖单；产物支持卖单或买单，默认买单。供应筛选仅影响候选和批量加入，不删除订单、不扣除库存；全部材料的在售数量须满足候选取整后的完整需求。

制造填写执行次数，0移除；次数包括烧毁。全部加入覆盖当前筛选的所有页，已有制造次数保持。收藏按完整物品ID保留来源和最高目标，同来源重复加入不降低目标，换来源须确认；已覆盖目标可点击移出订单。批量收藏取每件物品的最高目标，替换来源前确认。

订单有名称、执行勾选、制造／收藏条目和费用。点击汇总行切换当前订单并展开详情；勾选、复制、删除独立操作。订单详情第一行依次为名称、批量设置次数及应用按钮，第二行依次为固定加工费、材料费率、工时单价，其后显示条目表格；窄屏保持分组和顺序并允许组内换行。批量设置次数仅应用到该订单的制造行。复制不复制角色进度或库存。汇总显示本订单的时间、完整材料成本、费用及建议售价，即使未勾选执行也保留本单估算。

“自动移出已完成的收藏目标”默认关闭。启用后，仅确认属于当前角色的有效快照能够触发移除；等待数据或同步失败不按默认值移除，实际改变订单才保存。

## 计算与显示

| 项目 | 规则 |
| --- | --- |
| 制造时间 | 固定执行次数乘单次动作期望时间，烧毁仍计执行次数 |
| 收藏 | 按现有进度到目标的缺口计算，考虑烧毁、被抓、品质概率与产量；计划执行次数向上取整，材料、时间及产物按取整后次数计算 |
| 角色修正 | 技能、工具、装备、房屋、精通、药水及有效世界增益，只读取自游戏 |
| 稀有度热门 | 使用来源worldTick及对应技能原始倍率，不以本机日期或未来计划时间推算 |
| 采购 | 先合并勾选订单的材料及预计产物，再扣除同品质银行、背包和预计产物；最终数量向上取整且不为负 |
| 材料成本 | 当前模式参与汇总订单的完整需求材料价值之和，复用订单材料成本口径，不扣库存或预计产物、不含加工费；库存未知不影响已知材料成本，缺价或需求未知则显示未知 |
| 采购成本 | 采购金额，按抵扣库存及预计产物后的需购数量计算；缺价、库存或数量未知时显示未知，需购为零时为0 |
| 库存／报价未知 | 显示未知，不默认为零；被阻断的预计产物不得抵扣采购 |
| 重复收藏 | 勾选订单之间同一完整物品ID的收藏目标重复时阻断汇总，未勾选订单不参与冲突 |
| 费用 | 固定费对有未完成任务的订单收一次；材料费率按完整材料价值含已有材料；工时费按计划动作时间，不含移动、回仓和成长 |

内部金额为金币和金币／分钟。界面加工费、工时价使用M和M/h，1M=100万金币；收藏成本阈值使用百万金币／100点（M/100），输入乘10000后以金币／点存入对应收藏模式的maxCost，显示时除10000；空字符串表示不限。非法数值及数量／金额溢出明确拒绝，不截断后继续计算。

绿色表示全计划材料已满足，琥珀色表示单个动作材料足够但存在共享竞争。当前动作和队列分别为紫色／蓝色边框；只依据实时任务数据，非法结构、断连或来源回退时清除高亮。进度变化不触发持久化。

## 编辑

重绘复用稳定节点；输入法、选择文本、滚动、拖动及下拉框展开时保留输入草稿与交互状态，必要的结构变更延后，数值和安全禁用状态继续更新。条目操作使用稳定ID，不按排序后的行号定位。

订单不提供文本或剪贴板导入导出；可在助手内复制订单。自动保存、重新载入和重置继续使用原存档格式；移除导入导出不会删除已有订单。

## 存储与验收

用户工作区version=2保存订单、当前订单、定价方向、供应筛选、自动移除设置及三套筛选；材料方向为materialPriceMode。GM按站点与稳定角色ID分桶，未知身份不读写。角色、库存、收藏、时间／tick、任务与行情只存本页内存；刷新／切角等待新数据，断连保留本页有效快照并标明状态。

version=2新增可选selectedMode字段（craft／collection／collectionGather）保存角色的模式选择；旧存档缺少时默认craft，存在但无效时拒绝加载并保护原值，读取不自动写回。重新载入恢复该值，显式重置回制造。正常用户保存包含该字段。

version=2新增可选collectionOrder字段保存制造收藏固定单；严格校验为固定ID和名称、启用、零费用且只含制造来源收藏条目，与制造订单ID不重复。字段缺失时仅在完整校验原用户数据后生成空固定单，读取不自动写回；存在但无效时拒绝，不默认覆盖。原orders及其混合条目、采集来源、费用、勾选和ID全部原样保留在制造模式，不自动搬运或合并。下一次正常保存写入固定单；旧版不支持该新增字段，不支持降级读取。没有独立采集订单。模式切换、重载及切角使旧预填失效，切走再切回也不能恢复；延后结构更新期间旧模式控件不可编辑新模式数据。

首次成功读取（包括确认空值）前禁止保存。保存串行合并，写前校验原值和待写值，比较revision并检查溢出；读取、校验或写入失败持续显示根因并锁定保护。读写互斥；revision检查不构成跨页面原子比较交换，按单页面运行，不监听其他页面。

重新载入只替换用户数据，不自动写回或移除收藏；确认空值后恢复默认用户数据。重置须确认，失败不更换当前工作区。两者同步筛选、展开状态，保留当前角色与行情。version=2新增可选filters.collectionGather，filters.collection继续保存收藏（制造），filters.craft保存制造；旧存档缺少collectionGather时，在完整校验原收藏筛选后复制为采集初值，界面按各模式技能范围显示（不适用技能显示全部），两套对象独立。仅缺少该字段视为旧格式，字段存在但无效时拒绝加载，不回退默认值；下次正常保存写入三套筛选，读取不自动写回。旧版脚本不支持新增字段，不支持降级读取。数据格式变更需单独设计与验证，未知结构保留原值，不用默认数据覆盖。

布局与调试开关按站点分别保存；移动端不写布局。演示使用独立localStorage和启动夹具，与正式GM数据隔离。

## 游戏同步与草稿预填

在document-start旁听既有同源连接，同时每250ms采样游戏客户端白名单。正常前台相关变化1秒内更新。客户端和服务器快照独立保留，优先有效客户端；连接、角色与序号守卫阻止迟到数据混用。非法世界tick／窗口或角色结构拒绝整份快照，保留有效数据并报告原因，恢复后清除对应同步错误。

行情只读固定公开API，连接后10秒检查周期内首次读取，此后距成功读取满5分钟刷新。失败保留本页已有报价和成功时间；行情变化不写GM。标题时间表示本机读取／接收时间，不代表持续健康检查。

购买／执行辅助仅为默认关闭的调试功能，不在安装描述和普通用户说明中推广。桌面标题空白处右键、移动标题长按打开菜单；开关保存成功后应用，非法偏好锁定关闭。关闭开关使等待中的操作失效，再次开启仍需重新点击。

用户点击后可进入市场或普通制造／采集菜单并预填草稿，不提交购买、开始、排队、停止或即时设置。优先唯一可见控件，读回物品、价格、数量和品质；控件缺失、重复、游戏拒绝输入、角色或计划变化均停止并明确反馈。市场详情通过“所有物品”返回；品质不可选时提示先备齐至少一次所需材料，不替换品质或修改输入模式绕过限制。

移动预填成功后关闭助手，失败保留；桌面保持显示。用户点击原生底栏且页面确认切换后关闭移动助手，包括再次点击当前标签返回主画面；原生导航未切换时保持显示。程序导航不触发此规则，返回主画面不自动重开。预填处理中与失败反馈在入口原位显示5秒，入口隐藏不丢失反馈。正常完成不提示，由用户在游戏中最终确认。

执行草稿预填时，移动端仅通过原生底栏进入技能页，不调用桌面 `panels.show('skills')`：该接口会隐藏背包和装备节点，移动端切回背包不会恢复。桌面仍通过该接口打开技能面板；双端随后共用配方选择和草稿预填。
