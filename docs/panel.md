# 面板与计算规则

## 双端设计原则

桌面与移动端共用业务规则、字段和操作。移动端只在布局、键盘及触屏交互上适配，不删减计算数据。面板使用游戏风格的Shadow DOM，语言跟随游戏；标题显示助手版本、角色读取时间及市场读取时间。

刷新默认关闭面板，入口就绪时不显示自动提示。关闭仅隐藏窗口，本页订单、草稿和滚动保留。桌面入口附加于游戏导航；移动入口仅在主画面聊天按钮上方显示，进入其他页面或弹窗后隐藏。

桌面窗口层级为9，移动端窗口层级为31。桌面标题可拖动，四边／四角可缩放；保存位置尺寸，避开游戏顶部工具栏。移动端顶边和左右贴合可视区域，只避开底部操作栏，适应系统键盘；不写回桌面布局。

正文分区按内容高度从顶部排列，保持固定间距；模式切换、筛选后内容减少或窗口增高时，不将剩余高度分摊到分区及其内部元素，空余空间留在正文底部。

移动表格12px字号，按钮、单行输入和下拉框32px高，数字输入16px字号。物品列72px，长名两行并可聚焦展开；宽表内部横滚，冻结物品与品质两列，保持底色及上下任务边框。订单汇总与详情使用同一横滚层，正文继续纵滚。

## 配方与订单

窗口全局设置位于配方区之前，模式从左到右为制造、收藏（制造）、收藏（采集）。材料／产物定价始终显示一组，不根据模式隐藏。首次使用默认制造，之后按角色恢复最后选择的模式；刷新仍默认关闭窗口。

各模式的范围如下：

| 模式 | 配方与计划 |
| --- | --- |
| 制造 | 配方、完整订单管理、采购与执行计划；仅合计勾选订单，支持制造和收藏混合条目 |
| 收藏（制造） | 配方、独立固定收藏单的采购与执行计划，不显示订单管理；配方不显示执行次数，次数在计划查看 |
| 收藏（采集） | 仅配方与草稿预填，不创建订单，不显示加入／全部加入订单；计算规则见下文 |

### 采集收藏

枚举各品质所有未完成档位对应的采集方案，无需选择目标；候选仅按显式筛选条件过滤。同一采集来源、相同期望执行次数合并为一项，不同来源分别展示。主表列为物品、精通点、时间、秒／点、执行次数、操作，不显示品质、当前→目标及金币相关列。仅冻结物品列；制造两模式冻结物品与品质列。

点击主行非操作区域或聚焦后按 Enter／空格展开各品质明细；明细区域点击不收起。明细列为稀有度、当前→目标、预计增加、精通点；目标为下一未完成档位，全部完成时显示已完成，零得点、零产量及已完成品质仍展示。不可产出品质的预计增加为0。展开状态仅存会话，切换模式时清除。

按同一次采集的期望次数、烧毁／被抓概率、产量与品质概率计算各品质产量，精通点为各品质按期望产量折算的新增点数之和，效率与阈值使用该合计。期望次数不取整，仅在整数数量边界消除机器精度误差，数量／合计溢出明确失败。“执行”按钮不触发展开，按最新候选的期望次数向上取整预填，不选择随机产出品质。界面说明收藏次数为期望估计、不保证完成目标，时间按直接丢弃采集物估算。

采集保留技能、搜索、点数及效率阈值和材料／定价选项，不显示品质筛选。旧存档 `tier` 严格校验并原样保留，但不参与筛选；旧 `rarity`、金币及金币／点排序在采集视图改用秒／点升序，读取时不写回。新工作区采集默认按秒／点升序，其他排序沿用既有交互。合并后排序分页，每页10个方案，明细不计分页。预填刷新角色后按原候选身份查找最新方案，合并候选沿用其中一个有效目标的身份。

### 制造与订单

收藏（制造）显示配方选择、采购材料和执行计划，不显示订单管理。候选加入独立的唯一固定订单，配方中保留已有移出／替换来源行为。执行计划按收藏条目展示，列为物品、稀有度、技能、执行次数、预计时间和操作，不额外显示目标列，支持按游戏阈值升降目标和移除；始终显示仅预填的执行。完成、不可计算及筛选外条目仍可管理；完成项不计动作。执行计划标题行右侧依次为“自动移除已完成”和“删除所有计划”；后者须确认，清空固定单全部条目（含完成、不可计算及筛选外条目），保留固定单、制造订单及其他设置，空计划时禁用。执行计划操作列始终将“执行”放在首位，收藏目标编辑按钮随后按＋、−、×排列；×保留“移除”可访问名称和悬停说明。固定单无名称编辑或费用。

收藏（制造）候选包含普通制造配方和游戏收藏目录内的装备／工具升级配方（含 95、99、105 级），按技能等级和已有筛选显示。升级每次确定产出一件同品质物品，次数按收藏缺口计算，材料与固定单次耗时复用制造模式；基础装备按同品质 +0 估值和采购，不推算其制造链。升级动作可管理计划，暂不支持执行草稿预填及实时动作高亮。

采购独立为分区，不在执行计划重复。“产物按期望估算”位于采购材料面板标题行右上角，其下并列显示材料成本与采购成本；双端保持相同信息层级。

### 筛选与加入

三个模式分别保存筛选、排序和页码（采集不使用品质），切换或刷新时恢复对应模式的值；修改筛选或排序仍回到第一页。筛选含技能、品质、名称搜索；收藏另含最低精通点、最高小时／100点和最高百万金币／100点，阈值为空表示不限。时间阈值在界面使用小时／100点，内部比较与存档仍使用秒／点（1小时／100点=36秒／点），已有存档按此比例换算显示，存档格式不变；表格时间效率列仍显示秒／点。每页10项，排序在分页前执行，未知值置末。

材料选项支持卖单、卖单（排除在售数量不足）、买单、库存（仅仓库材料），默认卖单；产物支持卖单或买单，默认买单。供应筛选仅影响候选和批量加入，不删除订单、不扣除库存；全部材料的在售数量须满足候选取整后的完整需求。

“库存（仅仓库材料）”包含同品质且未锁定的仓库与背包材料，不计预计产物，材料仍按卖单估值。制造候选按一次执行需求筛选，收藏候选按达到目标的取整执行次数完整需求筛选。各候选独立判断，不预留共享材料，批量加入可能产生共享竞争；已有订单、次数、采购缺口及费用计算保留。库存未知时明确提示，需材料的候选不可确认满足，无材料需求的采集候选保留。库存同步后重新筛选，切换材料选项回到第一页。

### 订单编辑

制造填写执行次数，0移除；次数包括烧毁。全部加入覆盖当前筛选的所有页，已有制造次数保持。收藏按完整物品ID保留来源和最高目标，同来源重复加入不降低目标，换来源须确认；已覆盖目标可点击移出订单。批量收藏取每件物品的最高目标，替换来源前确认。

制造配方表的当前订单次数框支持Tab跳到当前页下一行可用次数框、Shift+Tab跳到上一行，按排序和筛选后的显示顺序导航；首尾无目标时沿用浏览器正常焦点顺序，不循环或翻页。跳转沿用失焦校验与保存，重绘保留目标焦点；物品名称仍可独立聚焦。输入法组合中或带Ctrl／Alt／Meta修饰键时不接管Tab。

订单有名称、执行勾选、制造／收藏条目和费用。点击汇总行切换当前订单并展开详情；勾选、复制、删除独立操作。订单详情第一行依次为名称、批量设置次数及应用按钮，第二行依次为固定加工费、材料费率、工时单价，其后显示条目表格；窄屏保持分组和顺序并允许组内换行。批量设置次数仅应用到该订单的制造行。复制不复制角色进度或库存。汇总显示本订单的时间、完整材料成本、费用及建议售价，即使未勾选执行也保留本单估算。

“自动移除已完成”默认关闭。启用后，仅确认属于当前角色的有效快照能够触发移除；等待数据或同步失败不按默认值移除，实际改变订单才保存。

## 计算与显示

| 项目 | 规则 |
| --- | --- |
| 制造时间 | 固定执行次数乘单次动作期望时间，烧毁仍计执行次数；装备升级按游戏的固定单次耗时计算；升级保留材料品质及强化，助手按 +0 材料估算 |
| 收藏 | 按现有进度到目标的缺口计算，考虑烧毁、被抓、品质概率与产量；计划执行次数向上取整，材料、时间及产物按取整后次数计算 |
| 角色修正 | 技能、工具、装备、房屋、精通、药水及有效世界增益，只读取自游戏；技能副手按适用技能计入速度，品质和强化沿用上游加成 |
| 稀有度热门 | 使用来源worldTick及对应技能原始倍率，不以本机日期或未来计划时间推算 |
| 采购 | 先合并勾选订单的材料及预计产物，再扣除同品质未锁定仓库与背包库存及未锁定的预计产物；最终数量向上取整且不为负 |
| 材料成本 | 当前模式参与汇总订单的完整需求材料价值之和，复用订单材料成本口径，不扣库存或预计产物、不含加工费；库存未知不影响已知材料成本，缺价或需求未知则显示未知 |
| 采购成本 | 采购金额，按抵扣库存及预计产物后的需购数量计算；缺价、库存或数量未知时显示未知，需购为零时为0 |
| 库存／报价未知 | 显示未知，不默认为零；被阻断的预计产物不得抵扣采购 |
| 重复收藏 | 勾选订单之间同一完整物品ID的收藏目标重复时阻断汇总，未勾选订单不参与冲突 |
| 费用 | 固定费对有未完成任务的订单收一次；材料费率按完整材料价值含已有材料；工时费按计划动作时间，不含移动、回仓和成长 |

纯煤配方（344）与普通煤配方（5）共用煤物品及收藏进度；`plain` 采集仅产普通品质，其品质分布不受角色与世界稀有度加成影响，稀有品质目标不列出该路线。候选、订单行及执行计划显示来源名称以区分路线；普通煤保留原品质分布。

内部金额为金币和金币／分钟。界面加工费、工时价使用M和M/h，1M=100万金币；收藏成本阈值使用百万金币／100点（M/100），输入乘10000后以金币／点存入对应收藏模式的maxCost，显示时除10000；空字符串表示不限。非法输入及数量溢出明确拒绝，不截断后继续计算。

总价、产物价值、费用、采购小计及金币／点使用有限非负浮点数估算，允许超过 `Number.MAX_SAFE_INTEGER`，不承诺逐金币精确；仅显示时舍入，排序、筛选和半成品比价使用未格式化结果。实际数量、期望数量、时间、点数、行情单价、费用输入及存档边界沿用原规则，不随估算金额放宽。

金额乘加或效率除法产生非有限值、负数或非法除数时，相关单元格明确显示「金额不可计算」，与缺价的未知值区分。候选保留其他信息和管理操作，金额排序时不可计算与缺价均置末，有金额上限时均排除；一行金额失败不清空全表。依赖失败金额的订单与采购合计也明确不可计算，不以部分金额冒充完整合计；独立数量、时间及其他有效金额继续显示。仅已识别的金额错误按此隔离，其他错误继续明确报告。金额失败本身不阻止有效数量和单价的草稿预填，涉及半成品路线不确定等数量依赖时仍阻断相应请求。[数值边界与验收规格](superpowers/specs/2026-11-13-large-amount-estimates-design.md)

绿色表示全计划材料已满足，琥珀色表示单个动作材料足够但存在共享竞争。当前动作和队列分别为紫色／蓝色边框；只依据实时任务数据，非法结构、断连或来源回退时清除高亮。进度变化不触发持久化。

### 考虑自制半成品

收藏（制造）的「考虑自制半成品」位于「材料」定价左侧，默认关闭，按角色保存。开启后，金属锭与切割宝石按同品质直购价和单层配方的原料价值择低。角色需达到配套动作等级且能够使用产物。同价优先直购，单边有完整报价时采用可估的可行路线，两边均缺价时保留需求并提示未知。 缺价只阻断该路线。共享原料的总需求取决于是否自制时，其采购量显示未知；独立材料仍可按已知缺口采购，收藏目标点数仍按原目标计算。

配方表按所选路线估价，成本排序与阈值使用同一口径。耗时仍为原配方动作耗时，供应筛选按原配方需求判断。固定计划按保存顺序先分配未锁定的同品质库存，再处理剩余缺口。已用库存按半成品报价计值，自制部分按原料计值。采购汇总统一抵扣可用库存和预计产物，直接添加的半成品收藏目标独立计算。库存未知时保留已知需求，标明未完整计算。

两种价格均已知且自制严格更便宜、计划确有配套动作时，采购表在半成品名称右侧显示暗金色小字「自制」。可点击的细铜边次选「购买」按钮按放弃配套自制后的缺口预填草稿，仍抵扣其他预计产物。配套动作按配方与品质合并并排在收藏目标之前，耗时纳入计划总时间，精通点按原收藏目标计算。完整判定、样式和算例见[设计规格](superpowers/specs/2026-11-12-consider-crafting-intermediates-design.md)。

## 交互状态

重绘复用稳定节点；输入法、选择文本、滚动、拖动及下拉框展开时保留输入草稿与交互状态，必要的结构变更延后，数值和安全禁用状态继续更新。条目操作使用稳定ID，不按排序后的行号定位。

订单支持助手内复制，不提供文本或剪贴板导入导出。

## 存储与恢复

用户工作区 `version=2` 保存订单、当前订单、定价方向、供应筛选、自动移除及三套筛选，材料方向为 `materialPriceMode`。GM 按站点与稳定角色 ID 分桶，未知身份不读写。角色、库存、收藏、时间／tick、任务与行情只存本页内存；刷新／切角等待新数据，断连保留有效快照并标明状态。

可选字段兼容规则如下。所有旧数据须完整校验后才能补充缺失值；字段存在但无效时拒绝加载并保护原值，读取不自动写回。

| 字段 | 缺失时 | 校验与正常保存 |
| --- | --- | --- |
| `inventoryOnly` | `false` | 布尔值；开启时材料方向须为 `ask` 且在售数量筛选关闭，选择其他材料选项关闭本筛选；正常保存写入 |
| `expandMetalBars` | `false` | 「考虑自制半成品」继承原「展开半成品」偏好，旧值 true 按新比价规则计算；布尔值，开启时写入 `true`，关闭保存时省略 |
| `selectedMode` | `craft` | 仅 `craft`／`collection`／`collectionGather`；重新载入恢复，显式重置回制造；正常保存写入 |
| `collectionOrder` | 空固定单 | 固定 ID、名称、启用、零费用，只含制造来源收藏条目，与制造订单 ID 不重复；正常保存写入 |
| `filters.collectionGather` | 复制已校验的 `filters.collection` 为独立对象 | 与其他筛选同样严格校验；正常保存三套筛选 |

`filters.craft`／`filters.collection` 分别保存制造／制造收藏筛选，视图中不适用的技能显示为全部。原 `orders` 的混合条目、采集来源、费用、勾选和 ID 保留在制造模式，不自动搬运或合并；采集没有独立订单。新增字段不保证旧版脚本能降级读取，更新前应备份。格式变更需单独设计与验证，未知结构不得以默认数据覆盖。

升级收藏条目的 `jobId` 使用制造模式既有的 `upgrade-<游戏配方ID>` 字符串，普通收藏仍为数字 ID；只接受该物品的有效来源，不转换或修补无效 ID。存档保持 `version=2`，旧版脚本不支持读取新增的升级收藏条目，降级前须移除这些条目并备份。

首次成功读取（包括确认空值）前禁止保存。保存串行合并，写前校验原值和待写值，比较 `revision` 并检查溢出；读写互斥，失败持续显示根因并锁定保护。`revision` 检查不构成跨页面原子比较交换，按单页面运行，不监听其他页面。

重新载入只替换用户数据，不自动写回或移除收藏；确认空值后恢复默认数据。重置须确认，失败不更换当前工作区。两者同步筛选及展开状态，保留角色与行情。模式切换、重载及切角使旧预填永久失效；延后结构更新期间旧模式控件不可编辑新模式数据。

布局与调试开关按站点分别保存；移动端不写布局。演示使用独立 localStorage 和启动夹具，与正式 GM 数据隔离。

## 游戏同步

每个模拟动作使用其技能绑定的整页精通，半成品按自己的配方选页。技能未绑定、所指页不存在或旧快照没有分页数据时使用当前生效页。已拥有的空页按零分配计算，切页等待按零处理。具体输入、异常和验收条件见[技能精通页规格](superpowers/specs/2026-11-12-skill-mastery-pages-design.md)。

在document-start旁听既有同源连接，同时每250ms采样游戏客户端白名单。正常前台相关变化1秒内更新。绑定或页内加点变化后重新估算，游戏上限为每项 200 级。仓库锁定按完整物品 ID 应用于同品质仓库和背包可用材料；旧快照缺少锁定字段时按旧版行为，锁定字段无效时拒绝快照。客户端和服务器快照独立保留，优先有效客户端；连接、角色与序号守卫阻止迟到数据混用。非法世界tick／窗口或角色结构拒绝整份快照，保留有效数据并报告原因，恢复后清除对应同步错误。

行情只读固定公开API，连接后10秒检查周期内首次读取，此后距成功读取满5分钟刷新。失败保留本页已有报价和成功时间；行情变化不写GM。标题时间表示本机读取／接收时间，不代表持续健康检查。

## 草稿预填

购买／执行辅助始终启用，操作列不受调试开关影响；实时角色来源、输入有效性和忙碌状态仍决定按钮能否使用。调试开关保留供以后使用，当前不关联任何功能，未保存偏好时默认关闭；已有偏好继续保留，不自动写入默认值。桌面标题空白处右键、移动标题长按打开菜单；开关保存成功后应用，非法偏好锁定关闭并明确显示错误，不影响购买／执行辅助。切换调试开关不取消等待中的预填。

预填点击时先刷新角色数据，再生成一次待填请求。等待和填入过程中继续刷新角色，角色变化仍按正常同步流程重绘面板。购买守卫按最新完整计划重新计算目标商品的购买请求，与点击时的请求比较；目标物品、购买数量、单价或搜索名称变化，或目标不再可购买时停止。其他材料的库存、产出或行情变化若不影响目标请求则继续，不用新值替换待填请求。执行守卫继续比较完整输入签名，覆盖当前模式订单、有效展开开关、角色初始化状态、材料定价方向、库存及锁定、收藏进度、角色修正、有效热门倍率和行情；采样时间和不改变计算结果的普通 tick 不使请求失效。两类操作均保留角色、实时来源及模式切换守卫。

用户点击后可进入市场或普通制造／采集菜单并预填草稿，不提交购买、开始、排队、停止或即时设置。优先唯一可见控件，读回物品、价格、数量和品质；控件缺失、重复、游戏拒绝输入、角色或计划变化均停止并明确反馈。购买草稿的数量和单价接受游戏显示的千位逗号（如 5,900），两项均须与请求的整数完全相符。市场草稿单价上限跟随游戏（当前为100亿金币），市场详情通过“所有物品”返回；品质不可选时提示先备齐至少一次所需材料，不替换品质或修改输入模式绕过限制。

移动预填成功后关闭助手，失败保留；桌面保持显示。用户点击原生底栏且页面确认切换后关闭移动助手，包括再次点击当前标签返回主画面；原生导航未切换时保持显示。程序导航不触发此规则，返回主画面不自动重开。预填处理中与失败反馈在入口原位显示5秒，入口隐藏不丢失反馈。正常完成不提示，由用户在游戏中最终确认。

执行草稿预填时，移动端仅通过原生底栏进入技能页，不调用桌面 `panels.show('skills')`：该接口会隐藏背包和装备节点，移动端切回背包不会恢复。桌面仍通过该接口打开技能面板；双端随后共用配方选择和草稿预填。
