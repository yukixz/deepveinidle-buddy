# 制造页面

设计索引（原实验室：../../DESIGN.md） · 当前状态（原实验室：../status.md）

本页描述本地待发布的订单制造功能；发布与本地变更状态见 当前状态（原实验室：../status.md）。中文导航“制造”、英文“Crafting”，网址 `/craft`（含尾斜线）。沿用共用页面规则（原实验室：../shared.md）的语言、导航、页脚、状态保留及窄屏规则。桌面左侧角色配置、右侧属性和结果，配色、面板、输入框、图标按钮、表格、排序与展开明细均与采集一致。

**模拟与期望统计**

制造次数、经验、耗时、回仓、成功／烧焦诊断次数与实际材料消耗保留原始模拟；指定品质主产物直接计算，烹饪按每次执行前烧焦概率累计正常／烧焦产物期望，宠物与坐骑按实际成功分支机会累计期望。活动礼盒保留原始模拟，未完成计划不外推为完成；期望产物估值减实际消耗成本得到利润。材料需求、购买预算及即时升级仍是确定性直接计算。配方表下提供双语说明，金色加粗原始模拟／数学期望，并明确礼盒例外、材料预算和即时升级。

期望输出支持有限非负小数及安全上限校验，计划／库存／材料仍要求安全整数；速率产物估值兼容小数；计划不再显示产物期望汇总；配方速率的产物期望仍用于估值。验收覆盖烧焦概率采样、成功后奖励、原始过程一致性、未完成状态、小数估值／汇总／精度及双语说明。验证记录见混合计算实施报告（原实验室：../../reports/work-expectation-implementation-2026-10-13.md）；计算依据见混合计算调研（原实验室：../../reports/work-expectation-research-2026-10-13.md）。

**范围与配置**

- 五技能为烹饪 cooking、锻造 smithing、制箭 fletching、草药学 herblore、制作 crafting；1.0.1196 有效配方（含即时升级）分别为 8、66、38、8、74 个，共 194 个；其中普通制造 177 个、即时升级 17 个。配方、分类、材料、等级、产量及经验来自原始定义；不含农耕、游戏原生订单操作、跨配方连续队列、自动抵扣上游产物或多随机种子期望。
- 默认烹饪、各技能等级 1、无工具／增益、次数为 0、游戏库存未读取、初始仓库自动、热门沿用游戏。配置顺序为导入、技能按钮、技能、工具与装备、药水、家园、精通、天赋、其它、模拟配置；只展示实际有效配置。工具为各技能对应工具及坐骑；随机品质幸运不改变制造的指定品质，不显示护符或猎手药剂。药水为矿脉灵药和疾行；家园为当前技能制造速度设施；精通为制造、经验、移动，天赋为口袋、快手及烹饪稳手。稳手说明采用当前游戏的相对概率口径，见采集章节。其它提供公会经验、世界增益经验、祝福与铁人模式；模拟配置依次提供初始仓库、利润周期与热门策略。

  利润周期默认每天，清空恢复每天；已保存的有效每小时／每天选择保留，缺失或无效值使用每天。
- 属性卡依次为技能等级、制造速度加成、经验加成（不含品质与动态热门）、移动速度、背包容量，复用原始加成函数，不把速度加成当作产量增幅。
- 制造角色配置、订单、当前编辑订单、执行勾选及游戏库存保存在新版独立存档 `dvi-crafting-orders-v1`。不兼容历史制造数据：首次读取新版时删除旧 `dvi-crafting-v1`，不迁移旧角色、计划或库存，不影响其他页面及全局价格。新版坏存档明确提示并阻止自动覆盖，用户明确重置制造存档后方可恢复保存；保存失败仍可在内存编辑并提示。角色导入仍使用 `read`，仅更新角色字段及模拟配置默认值，保留订单、加工费和执行选择，同时从同一捕获更新库存；角色及库存任一必要校验失败均保留原值。切换技能、语言或页面保留订单及结果。各导入区域首次展开，其余配置首次折叠。

**适用增益与角色模式**

- 世界增益经验与战斗／采集共用捕获校验和全部有效窗口汇总规则（见战斗配置（原实验室：combat.md#335-完整手动模拟条件））；不按每周目标名称筛选，不取整。默认 0%，范围 0–10000000%，步进 0.1%，允许更细小数；手填和导入均全程生效，适用于普通制造的速率及计划模拟。新版订单存档保留已有经验值。旧捕获缺 `worldBuffsVersion: 1` 或世界数据异常时经验清零，单独提示更新脚本／手动配置，其它角色字段仍正常导入。
- 其它增加“铁人模式（不掉落坐骑）”，默认关闭；支持导入、保存、技能切换，清空角色配置恢复关闭。原始模拟及坐骑期望均禁用坐骑，其它产物和宠物规则保持原样。
- 不显示制造世界稀有发现、护符、猎手药剂、幸运家园或稀有精通：当前普通制造均消耗指定品质材料、产出指定品质，且无额外品质奖励；原始坐骑概率及品质不读取世界稀有度。即时升级仍采用固定经验、确定产物及零耗时，不受上述世界经验或铁人模式影响。
- 验收覆盖任意名称／重复／起止边界窗口、小数与新版存档、空／异常／旧捕获、经验属性卡与全部热门模式、五技能原始过程对照、铁人坐骑禁用、双语窄屏、导入保存重置、配置变化的速率与计划缓存失效。

**烟花制造**

制作技能新增五种烟花，配方 420–424、产物 701–705，火药 700 为固定普通品质材料。产量、经验与品质支持直接取原始定义；存在可变品质输入时才能保留所选品质，否则只提供普通行，计划校验拒绝不支持的品质。烟花参与制造、材料预算、库存与价格，不进入收藏目标或收藏计点。火药无市场分类、不可出售，商人卖出价为未知；通过材料表手动填写价格并保留缺价提示，不用购买价冒充卖出价。验收覆盖全部烟花品质、火药不变品质、产量、翻译、分类、五品质原始过程对照及保存往返；制造最近工作点、食物补给及热门设置按新版原始实现核验。

**订单编辑与配方选择**

- 左侧角色配置与属性卡保留，右侧按配方选择、订单管理和执行计划排列；订单编辑、当前订单配方清单与订单列表合并到同一独立订单管理面板，位于配方选择下方。配方选择标题栏同行显示当前编辑订单名称，长名称自然换行且不挤压计算状态，不再在标题下单独占一行。订单管理面板从上到下为标题／新建、全部订单表、合并的订单明细（名称、三项加工费、配方与统一次数操作）；点击订单行切换编辑对象，当前行高亮，不提供“当前订单”下拉框、独立设置／配方标题及订单批量执行／删除操作。订单行支持键盘Enter／空格切换；点击行切换前提交当前字段的合法修改，不能因重绘丢失点击；勾选执行、复制及删除独立操作不触发行切换。桌面名称和三项加工费四个输入同一行，窄屏两列换行；不展示“三项费用相加…”说明及对应英文；沿用共用面板及双语布局。
- 新建及复制订单可命名，默认勾选执行。每个订单包含多个跨技能配方；当前编辑订单与执行选择相互独立。配方筛选不影响订单内容。初次进入、读取有效空存档、重置制造存档或删除最后一个订单时，自动建立并选中一个默认勾选执行的空订单，可直接填写配方数量；读写异常继续明确提示且不覆盖坏存档。
- 保留分类、双语搜索、五品质多选（默认仅普通）、只看已填写、排序、重新模拟及原七列表格；最后一列改为当前订单制造次数。有效数量提交（change）即加入或更新当前订单，无加入按钮；空值或0移除，非法值不写入。次数为非负安全整数，包含烧焦；详情显示单次产量。等级不足仍可加入并保留提示。
- 同订单同配方＋品质只保留一条，不同订单可以重复。当前订单清单显示全部跨技能条目，可改数量或移除。统一制造次数只替换当前订单已有全部配方（包括筛选隐藏项），不新增候选、不影响其他订单；批量0经确认后清空当前订单配方。
- 三项加工费输入均可同时填写，留空按0计算且 placeholder 为0：固定金币／订单、材料成本百分比、金币／分钟。非负有限数值，超安全范围拒绝；空订单不收费。
- 加工费＝固定费＋全部材料消耗估值×比例/100＋独立估算分钟数×时间费率。比例基数不抵扣库存；时间按订单各配方独立模拟合计，包含移动、取料和中途回仓，即时升级为0，未舍入分钟计费。费用单独作为加工报酬，不自动加到产物售卖利润；无时间费时不因模拟等待阻塞已知费用，有时间费且结果未完整时总费为未知，仍展示已知分项。缺价兜底沿用制造规则并明确标记；费用溢出报错。

**订单选择与执行计划**

- 订单表列为执行、名称、配方数、材料成本、预计耗时、加工费、操作。按整个订单勾选或取消，即启用／停用；空订单允许勾选，制造次数、材料与加工费均为0；填写配方后立即纳入计划。清空配方保留原勾选，用户主动取消执行的状态也继续保留。点击订单行编辑，操作列只提供复制与删除，单条删除经确认；不提供全选、全部取消或删除所选。复制保留配方和费率，使用新标识并默认勾选执行。
- 执行计划只有一个，勾选或修改已选订单后即时重算。配方制造清单按配方＋品质汇总次数，可展开各订单贡献。材料按全部所选订单的完整物品ID合并，品质独立，库存只抵扣一次。不用其他订单预计产物抵扣需求。
- 费用、经验、耗时和产物统计按订单内配方独立估算；相同配方、品质、次数可复用同轮结果，不能把跨订单总次数模拟结果拆分收费。不同次数使用各自缓存。配方清单合并仅用于展示与材料汇总，不改变独立计算口径。
- 订单与执行选择独立于角色配置清空。逐单勾选仅调整执行选择；删除订单不清库存。清空角色配置保留订单、费率及库存；订单删除后当前编辑项切换到下一有效订单，删除后无订单时自动创建默认勾选的空订单。
- 保留普通制造24小时独立速率及每小时／每天显示切换，周期切换不重跑；配方与品质筛选、排序、搜索和价格变化不重抽种子。订单数量变化不清速率缓存；配置变化与重新模拟开启新轮并隔离旧Worker结果。

**装备升级**

- 不新增独立升级表。现有配方表排除 retired 的十项持续制造配方，加入原始十项替代与七项新增，共 17 种升级配方，分类为“升级 / Upgrades”，沿用技能、搜索、品质筛选、排序和计划数量。升级与普通配方原始数字编号有重叠，保存键使用 `upgrade-编号:品质` 区分。
- 升级仅按无强化底装（+0）估算，不提供底装强化输入；底装、产物和额外材料按原始函数映射完整品质编号。升级配方名称及展开详情不追加“即时升级 · 底装 +0”说明；制造次数/小时或天栏显示“即时升级”，经验／利润显示数值与“/次”单位，明确不属于对应小时／天速率。原游戏仍可保留强化，本页不模拟此类升级。
- 1.0.1190 巨像六件升级（271–276）仅消耗同品质 +0 陨铁底装与巨像碎片，不再消耗陨铁锭；其余升级材料、等级、固定经验与产物保持原始定义。订单按当前配方规则计算需求，无需求的库存继续隐藏保存。独立验收：两次传说巨像之剑需两把 4114 与四份 4252，不需 4044，经验为 3800；覆盖六件五品质和预算／库存兼容。
- 共用材料需求和汇总纳入 +0 底装及额外材料，已有数量仅扣购买预算，底装仍计入消耗价值。复用原始升级函数核验单次转换后，按计划次数累计固定经验和确定性产物，耗时 0；不套用制造速度、热门或经验倍率。等级不足仍计入计划需求，但不视为已完成。
- 固定品质行独立供给，不新增混合库存“优先好材料”模式。验收覆盖 17 种升级、五品质、固定经验／零耗时、底装完整编号估值、材料合并与数量合并安全、等级不足、双语和窄屏，并核验普通制造与新版 offline 对照。

**原始制造与统计**

- 合成模拟角色不参与每日／每周任务；1.0.1190 自动领奖不计入经验、金币或利润。每次原始 tick 前按原始日／周函数同步空任务的周期编号，避免重置时生成账号任务；不改原始引擎。验收覆盖自动领奖机会与跨日／跨周边界，独立原始离线对照以相同空任务条件分段执行。

- 普通制造复用原始品质材料映射、工作完成概率、经验、烧焦、路线与回仓逻辑；原始 route.limit 按执行次数减少，成功和烧焦各减一次。每行从相同初始角色独立开始，以对应等级最低经验为起点，正常升级，不连续执行多行。初始背包为空、材料按计划供给、仓库容量无限、药水和祝福全程有效。
- 原始输入映射会让部分材料跟随品质，部分保持基础品质，不统一转换所有材料。产物使用指定制造品质，非随机采集品质。经验按成功制造事件逐次取整；品质经验倍率为原始 1 / 1.5 / 3 / 8 / 25；烹饪先消耗材料，烧焦没有本次制造经验，保留烧焦产物。热门按所选技能和实际模拟时刻作用。
- 完成次数达到计划后停止计时，不追加最后存仓时间；计时包含初始移动、取材料、工作与中途回仓。默认自动仓库从仓库 1 初始化后，按原始客户端距离选择最近合法制造点；手动仓库从该仓库初始化。首版不增加地点选择器或全点平均。
- 制造每轮生成一个 32 位无符号随机种子，同轮全部配方、品质、24 小时速率及计划模拟共用，通过原始 context 传入；热门默认仍为“沿用游戏设置”。工具栏提供紧凑的“重新模拟”按钮，取消旧任务并清空速率／计划缓存，更新本轮时间与种子后重新计算当前技能及全部订单内的跨技能配方；配方展开明细显示本轮种子。角色计算配置变化与刷新开启新轮；技能切换、筛选、搜索、排序、语言、周期、价格与已有数量变化不重新抽样，计划次数调整沿用本轮种子及速率缓存。程序接口默认 seed 0，可显式传入复现；随机源失败明确提示，不回退。
- 大数量安全边界：单行最多计算 30 个游戏日，Worker 提供进度并可由配置变化中止；达到边界时保留实际完成次数、经验、已执行机会的产物期望、实际消耗、耗时及明确的未完成提示。显示全额计划材料成本，实际消耗仅用于利润计算、不单列汇总卡片；不把部分结果当作完成。材料按计划需求一次供给；超过时长边界可完成上限的计划，仅供给至每刻最多完成一次的理论上限，保持原始取材批量和回仓行为，不人为增加取材次数。数量／金额溢出明确报错。
- 材料总成本 = Σ计划需求×单价；利润 = 产物期望价值−实际消耗成本（活动礼盒数量保留模拟）。完整结果两者一致；药水成本、市场手续费及最终售卖耗时不计入，不套用强化 1.03 系数。非主要物品奖励单列在产物明细，不漏计或重复计价。

**材料表、价格与汇总**

- 列为材料、品质、需要采购、库存 / 总需求、单价、采购金额。库存只读，成功读取角色快照后取仓库 bank 与背包 pack 合计，重复背包堆叠先合并，完整物品ID／品质独立，不含装备或溢出。无需求库存仍保存。合并列显示库存 / 总需求 · 覆盖率，覆盖率向下取整且上限100%，数字不拆分。需要采购=max(总需求−库存,0)。仅汇总采购金额，不相加不同物品数量。
- 单价沿用全局价格；合法改价同步全局并自动锁定，0有效，缺价用商人估值并警告，不承诺实际可购买。库存只减少采购预算，不减少材料消耗估值及比例加工费基数；库存覆盖后采购为0时不提示采购缺价。
- 不展示“计划汇总”面板或跨订单的经验、产物价值、利润、时间和加工费总计；订单列表继续显示每单材料成本、预计耗时和加工费，执行计划保留配方制造清单、材料需求与采购金额合计。等级不足、等待、失败或30日上限未完成的原因继续在订单和配方来源明细显示；材料需求仍完整列出，数量和金额超限明确报错。
- 制造页的配方选择、订单配方与计划配方表中，“配方”列表头、名称与展开明细统一右对齐，与数值列一致；只调整显示，不改变排序与计算。制造页全部表格的数量与单价输入保留普通输入框的36px高度，通过缩小输入所在单元格的上下留白使其不撑高表格；在其他内容相同时，含输入框与纯文本行等高，复选框和文字操作不得额外撑高，保留焦点轮廓。库存列不再提供输入框；表外角色配置、订单名称和费用输入不调整。表格内部横向滚动，首列保持可读；沿用共用双语、键盘、输入焦点、展开与滚动保留规则，页面无横向溢出。

**游戏库存读取**

- 通过共用角色自动更新（原实验室：../shared.md#导入游戏角色与自动更新）管理两个开关，角色配置默认关闭、库存默认开启。库存开关开启时，进入制造页及该页激活期间每次窗口聚焦，通过现有只读角色桥接 read 获取库存；不轮询、不要求安装新脚本版本，不自动修改制造角色配置、订单或费率。执行计划标题提供“刷新库存”，与自动读取共享忙碌状态；手动角色导入也从同一快照更新库存，避免重复读取。
- 读取中／成功捕获时间／失败原因使用同一状态行；库存刷新仅重算采购，不使速率或订单模拟缓存失效。尚无库存时库存、采购数量和采购金额显示—，不以0冒充已读取；已知空仓库与空背包才按0抵扣。
- 复用收藏页的仓库／背包校验，任一缺失、堆叠非法、数量非安全整数或合并超限均原子拒绝；失败保留之前有效库存及其捕获时间，不以新时间伪装旧数据。过旧快照不覆盖新库存，切页／重置存档时的迟到响应不得写入；同一时间只进行一次角色／库存读取。
- 库存与捕获时间随新版订单存档保存，旧手填 owned 不再作为游戏库存使用，旧订单及角色配置保留，库存先显示未知直至读取成功。清空角色配置保留订单及游戏库存，重置整个制造存档则清除。自动读取不改变收藏页面自身数据或设置。自动配置更新仅导入角色字段，不改库存；两项同时开启时从同一快照原子更新。
